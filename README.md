# EPS Pulse

Je veux créer une web-app éducative appelée "EPS Progress".

C'est un outil destiné aux enseignants d'EPS et à leurs élèves.

IMPORTANT :

- Ce n'est PAS une application mobile à installer.

- C'est un site web responsive qui doit fonctionner parfaitement sur smartphone, tablette et ordinateur.

- L'interface élève doit être pensée en priorité pour un téléphone.

- Le design doit être moderne, sportif, motivant et très visuel.

- Il ne faut surtout pas que l'interface ressemble à un tableur ou à un logiciel administratif.

Le site aura deux espaces :

1. un espace élève

2. un espace enseignant

L'élève pourra consulter :

- son profil EPS

- ses activités

- ses compétences

- son niveau sur 5

- son historique de progression

- ses objectifs

- ses réussites

L'enseignant pourra :

- gérer ses classes

- gérer ses élèves

- créer des activités

- créer des compétences

- définir 5 niveaux de compétence

- évaluer les élèves

- consulter leur progression

Pour le moment, je veux uniquement créer la première version visuelle du site avec des données fictives.

Ne crée pas encore la base de données réelle.

Ne crée pas encore l'authentification.

Je veux d'abord obtenir une interface très esthétique et fonctionnelle avec des données de démonstration.
